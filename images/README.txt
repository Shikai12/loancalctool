IMAGE PLACEHOLDER NOTES
========================

This directory needs the following images before deployment:

1. images/about/author-james-whitfield.jpg
   - Author avatar for about.html and article bylines
   - Recommended: 400x400px, square crop

2. images/og-default.jpg
   - Default Open Graph image for social sharing
   - Recommended: 1200x630px

3. images/blog/{slug}.jpg (30 images total)
   - One per article, matching the article slug
   - Recommended: 800x450px, 16:9 ratio
   - Example: images/blog/no-fee-loan-trap.jpg

All images should be optimized for web (JPEG, 80% quality, <200KB each).
